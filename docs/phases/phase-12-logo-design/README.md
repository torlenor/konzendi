# Phase 12 logo candidates

These files are discovery artifacts. They are not production assets. Open
[`review.html`](review.html) in a browser to compare the vector studies at their stated CSS
sizes. The generated boards show the ideas in a broader tray and README context, but their size
labels are illustrative and are not measurements. The review page uses the two-colour study on
the light strip and converts it to one light colour on the dark strip. The first rendered check
showed that fixed petrol and blue artwork loses its petrol shapes on the dark strip. The final
production contract therefore uses separate README sources and a contrast-keyed static tray
source.

## Brief

The mark must identify a quiet desktop instrument that records topic switches. It must be calm,
compact, and clear beside other work. It can refer to continuity, switching, or the append-only
record. The owner wants the mark to include a brain. The brain represents contexts and reflection;
it must not imply intelligence, a productivity score, a cognitive or mental-health measurement,
surveillance, urgency, or speed. Use a simplified silhouette rather than anatomical detail.

The mark must work without a wordmark at tray size. The README keeps the exact word `Konzendi` as
its text heading instead of embedding a font in the image. A production source must support
one-colour output. The Phase 6
palette can supply a petrol base (`#0d151a`), a cool light foreground (`#dbe5ea`), and live blue
(`#6fb2e8`). A colour variant must not make blue decorative if it could be read as tracking state.

## Selected direction

The owner selected **F. Threaded Mind** on 13 September 2026, specifically the character shown
in its generated context board. Preserve these features while refining it:

- four broad, asymmetric, rounded brain lobes;
- petrol at upper-left and lower-right;
- blue at upper-right and lower-left;
- one uninterrupted vertical spine, which represents the append-only record; and
- a plain `Konzendi` wordmark, without a slogan.

Candidates A to C do not contain the requested brain. D makes the switching path compete with
the brain, and E omits the event-record thread. Keep those candidates only as decision history.

The owner selected **F1. Balanced** as the final geometry on 13 September 2026. F2 does not
improve the 16 px silhouette enough to justify its extra shaping. F3 weakens the event-record
idea by shortening the spine. Keep both refinements as decision history.

## Selected source contract

- [`threaded-mind-balanced.svg`](threaded-mind-balanced.svg) is the canonical two-colour source.
- [`threaded-mind-balanced-mono-dark.svg`](threaded-mind-balanced-mono-dark.svg) is the petrol
  one-colour source for light backgrounds.
- [`threaded-mind-balanced-mono-light.svg`](threaded-mind-balanced-mono-light.svg) is the cool
  light one-colour source for dark backgrounds.
- Each source uses a transparent 64 by 64 view box. When the mark is placed beside other content,
  keep external clear space equal to at least the 6-unit spine width. This is layout space beyond
  the SVG view box, not transparent padding inside it.
- The minimum test size is 16 px. The tray has one 32 px runtime PNG. The 16, 22, 24, and 32 px
  renders are the visual test matrix; they are not separate runtime assets.
- The README treatment uses the two-colour mark at 80 px before the existing `# Konzendi`
  heading. It uses petrol and blue on light backgrounds, and cool light and blue on dark
  backgrounds. The text heading remains the fallback if the image does not load.
- The tray treatment uses the same F1 geometry. Petrol regions have a cool light keyline, and
  blue regions have a petrol keyline. A centred 4-unit stroke in the 64-unit view box makes the
  keyline one physical pixel at 16 px. This keeps one static icon visible on light and dark
  panels without assuming that the application theme and panel theme agree.
- Window, installer, package, favicon, and platform-specific icon sets remain unchanged. This
  phase changes only the tray and README assets unless real integration evidence requires more.

The repository has no `LICENSE` file. The owner selected an asset-specific
[all-rights-reserved notice](RIGHTS.md) for F1, its monochrome variants, and derived exports. The
notice does not apply a licence to other repository files and does not imply trademark

## Candidates

### A. Continuity Gate

![Continuity Gate vector study](continuity-gate.svg)

A continuous path crosses an open gate. The path refers to work continuing through a context
switch. The gate gives the mark a compact boundary without putting it in a generic app tile.

- Strength: it has the most distinctive outline and the strongest continuity idea.
- Risk: the crossing can become busy at 16 px. The two colours can also imply active state.
- Generated context board: [continuity-gate-study.png](continuity-gate-study.png)

### B. Switch Lanes

![Switch Lanes vector study](switch-lanes.svg)

Three lanes show available contexts. One line changes its lane while the other structure stays
stable.

- Strength: it communicates a switch most directly and uses large shapes.
- Risk: it can resemble a menu or a generic routing symbol.
- Generated context board: [switch-lanes-study.png](switch-lanes-study.png)

### C. Event Thread

![Event Thread vector study](event-thread.svg)

An unbroken thread carries three recorded events. The side change refers to a context switch,
while the thread refers to the append-only record.

- Strength: it is compact and has the simplest small-size geometry.
- Risk: it can resemble sliders or controls and can look less like an identity mark.
- Generated context board: [event-thread-study.png](event-thread-study.png)

### D. Neural Gate

![Neural Gate vector study](neural-gate.svg)

A continuous switch path crosses a simplified brain-shaped gate. This is the most direct merge
of the original preferred candidate and the requested brain.

- Strength: it preserves the continuity idea and makes the brain explicit.
- Risk: the crossing competes with the brain silhouette at 16 px.
- Generated context board: [neural-gate-study.png](neural-gate-study.png)

### E. Split Focus

![Split Focus vector study](split-focus.svg)

Two broad brain halves are separated by an S-shaped negative-space path. The path suggests a
context switch without an arrow or anatomical detail.

- Strength: it has the clearest brain silhouette and the simplest combined idea.
- Risk: without the Konzendi context, the S-shaped gap can look decorative.
- Generated context board: [split-focus-study.png](split-focus-study.png)

### F. Threaded Mind

![Threaded Mind vector study](threaded-mind.svg)

Four broad lobes attach to an unbroken central record. Alternating colours refer to changing
contexts.

- Strength: it preserves the append-only thread and remains compact.
- Risk: it can still resemble a control or a butterfly at small sizes.
- Generated context board: [threaded-mind-study.png](threaded-mind-study.png)

## Closed discovery and remaining implementation evidence

The selected F1 geometry must satisfy these checks:

1. It is recognisable at 16, 22, 24, and 32 px.
2. It does not suggest scoring, health measurement, surveillance, urgency, or speed.
3. It identifies Konzendi without the wordmark.
4. It stays quiet beside the Readout interface.
5. Its one-colour form keeps the same meaning.

Blue remains in the static tray mark. The production locations, deterministic export rule,
runtime failure behavior, and README light/dark treatment are defined in the
[phase document](../phase-12-logo-design.md#production-asset-contract). Implementation must still
test the real tray host and record its rendered box. The selected mark is all rights reserved.
Do not reopen the geometry unless a real tray-host result shows that it fails.

## Provenance

The nine PNG context boards were generated with OpenAI's built-in image generation tool on 13
September 2026 from project-specific prompts. The SVG studies were redrawn in this repository as
small-size geometry probes. No third-party logo or font artwork was used as an input. The PNG
boards contain generated visual effects and typography; do not export production assets from
them.
