# Security policy

## Supported versions

Konzendi is a prototype. Security fixes are made on `main` and in the latest release. Older
prereleases do not receive security updates.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting](https://github.com/torlenor/konzendi/security/advisories/new)
form. Include the affected version, the impact, reproduction steps, and a proposed fix if you
have one.

Do not include real tracking logs, credentials, or other personal data. Use synthetic data in
the report.

The maintainer will acknowledge the report, investigate it, and coordinate disclosure and a
fix when the report is valid. There is no paid bug bounty program.
