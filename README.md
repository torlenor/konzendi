# Konzendi

A project exploring a simple, robust tool for people working on a computer, especially
developers and engineers, to understand context switching and reflect on their working habits.

The workspace currently contains planning documentation. Konzendi is the product name, and the
first deliverable is decided: an offline-only Tauri desktop application on Linux with local,
per-device data and no accounts. That foundation has not been built yet, so there is no
application to install or run. The prototype's feature scope, scoring, synchronization, and
commercial model remain undecided.

Start with the [roadmap](docs/ROADMAP.md), then the
[open questions](docs/OPEN_QUESTIONS.md). Working conventions live in [AGENTS.md](AGENTS.md).
The [original concept](docs/brainstorming/context-switching-app-concept.md) preserves the
product discussion and proposed options; it is not an approved implementation specification.
